# Typora Live Markdown

A local VS Code extension that adds a Typora-style Markdown workflow:

- Live Markdown preview that updates as the source document changes.
- `Ctrl+/` toggles Markdown source mode and preview mode.
- Inline LaTeX with `$...$`.
- Display LaTeX with `$$ ... $$`, including multiline blocks.

## Run locally

```bash
npm install
npm run compile
```

Then press `F5` in VS Code to launch the Extension Development Host.

Open a Markdown file and use `Ctrl+/` to switch between source and preview.
